# AI 使用说明

本次使用 AI 阅读 PRD 和被测代码、提炼风险与边界条件、起草 pytest 用例和交付文档。AI 没有修改 `app.py`。

关键 prompt 示例：

1. “对照 PRD 与 FastAPI 实现，找出需求不一致点，给出可复现步骤、预期和实际。”
2. “按两天测试时间设计核心 API 测试，覆盖业务闭环、阈值边界、异常和状态隔离。”
3. “为这套服务编写可重复运行的 pytest 自动化，至少一个跨接口完整流程。”

我将生成的测试与 PRD 逐项核对，调整了时间戳以固定复现结果，并把未定义行为列为疑问/假设。由于环境中依赖未安装，尚未执行测试；应安装 README 所列依赖后确认测试输出。AI 不适合替代真实产品决策（如乱序时间戳处理和告警冲突策略），也不应代替对测试结果的人工审查。
